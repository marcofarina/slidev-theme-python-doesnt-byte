# Un oggetto è dati più comportamento

Prima di scrivere una classe, serve sapere che cosa deve fare.

- una **classe** descrive lo stampo
- un'**istanza** è un oggetto costruito dallo stampo
- un **metodo** è una funzione che appartiene alla classe
